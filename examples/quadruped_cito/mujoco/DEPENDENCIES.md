# MuJoCo bridge dependencies

The simulator bridge is optional and does not affect default ContactIPM builds.
Its reproducible dependency set is:

- MuJoCo `3.9.0`, installed from the official CPython 3.11 Linux wheel. The
  wheel contains the native C headers and `libmujoco.so`; the C++ bridge does
  not import Python at runtime.
- MuJoCo Menagerie commit
  `da76818e269b82289eba39808e2fb91d679d6994`. The setup downloads the pinned
  Go1 XML directly and removes only its non-colliding visual mesh declarations.
  Masses, inertias, joints, primitive collision geometry, foot contact
  parameters, and actuator force limits remain unchanged.

From WSL, run:

```bash
bash examples/quadruped_cito/mujoco/setup_mujoco_wsl.sh
cmake -S . -B build-mujoco \
  -DNMPC_BUILD_MUJOCO=ON \
  -DMUJOCO_ROOT="$PWD/.deps/mujoco-py311/mujoco" \
  -DMUJOCO_MENAGERIE_ROOT="$PWD/.deps/mujoco_menagerie"
cmake --build build-mujoco --target \
  quadruped_cito_mujoco test_quadruped_cito_mujoco_adapter \
  test_quadruped_cito_go1_flat test_quadruped_cito_go1_smooth \
  test_quadruped_cito_go1_slope test_quadruped_cito_multifoot \
  test_quadruped_cito_long_horizon
cd build-mujoco
ctest -L quadruped_cito_mujoco --output-on-failure
```

The MuJoCo label runs the convention audit, 60 s standing replay, native flat,
smooth, and slope plan exports/replays, both multifoot orderings, one combined
robustness case, the 6 s flat/sinusoidal plans, and expected-failure
uniform-force and fixed-schedule timing baselines. Exported plans and robustness
CSV/logs are temporary build artifacts regenerated by fixtures or
`run_robustness.py`.

The dependency directories and build directory are ignored by Git.
